# Speed Tracker PWA

A Progressive Web Application that tracks your speed using the browser's Geolocation API.

## Features

- Real-time speed tracking in miles per hour
- Works offline (PWA)
- Clean, modern UI
- Responsive design
- Installable on mobile devices

## Usage

1. Open the application in a modern web browser
2. Click "Start Tracking" to begin monitoring your speed
3. Allow location access when prompted
4. Your current speed will be displayed in miles per hour
5. Click "Stop Tracking" to end the session

## Technical Requirements

- A modern web browser that supports:
  - Geolocation API
  - Service Workers
  - PWA features
- Location services enabled on your device
- HTTPS connection (required for geolocation in most browsers)

## Installation

To install as a PWA:

1. Open the application in Chrome/Edge/Safari
2. Click the install icon in the address bar (or use the browser's menu)
3. Follow the prompts to install the application

## Development

To run locally:

1. Clone this repository
2. Serve the files using a local web server
3. Access the application through `localhost`

## Notes

- Speed accuracy depends on your device's GPS capabilities
- Some browsers may require HTTPS for geolocation to work
- The application works best on mobile devices with GPS
